Αποθήκευση
Η ικανότητά σου να ενθουσιάζεις τους πελάτες εξυπηρετώντας τους με αυτοπεποίθηση θα κάνει τη διαφορά. Οι πελάτες μας εμπιστεύονται τη M&S. Θα βασίζονται στις συμβουλές σου για να τους βοηθήσεις να βρουν αυτό που είναι κατάλληλο για εκείνους. Για να το καταφέρεις αυτό, θα πρέπει να είσαι πάντα ενημερωμένος για όλα τα προϊόντα και τις προσφορές μας, και να ακούς προσεκτικά τις ανάγκες των πελατών μας. Με αυτό τον τρόπο, το ταλέντο σου στην επιλογή των σωστών προϊόντων και στη δημιουργία μίας εξαιρετικής αγοραστικής εμπειρίας θα φανεί.
Έχεις πάθος για τα προϊόντα, όρεξη για εργασία και πρωτοβουλία, διάθεση να παρέχεις εξαιρετική εξυπηρέτηση και να συνεργαστείς ομαδικά; Αν θεωρείς ότι διαθέτεις τα παραπάνω, αισθάνεσαι περήφανος/η για ό,τι έχεις κατακτήσει, έχεις καλή γνώση Αγγλικών και αξιοποιείς κάθε ευκαιρία που προκύπτει για να εξελίσσεσαι, ώστε να είσαι επαγγελματίας στο ρόλο σου, είναι η κατάλληλη στιγμή να εξελίξεις την καριέρα σου στη M&S!
Αν επιθυμείς να γίνεις μέλος μιας δυναμικής ομάδας και να κάνεις καριέρα στο χώρο της λιανικής, στείλε μας το βιογραφικό σου.
