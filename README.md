# Αγγελίες εργασίας — καθημερινή συλλογή

Κάθε μέρα στις 13:25 UTC το GitHub Actions τρέχει το `collect.py`, που μαζεύει αγγελίες από
kariera.gr, Workable, jobfind.gr, Ίδρυμα Ωνάση, alfavita και proson και γράφει:

- `data/recent.json` — οι αγγελίες που εμφανίστηκαν για πρώτη φορά τις τελευταίες 3 ημέρες
- `data/details/<πηγή>/<id>.md` — πλήρες κείμενο και σύνδεσμοι αίτησης κάθε αγγελίας
- `data/excluded.json` — όσες κόπηκαν αυτόματα από τον τίτλο, με τον λόγο
- `data/run_report.md` — τι διάβασε κάθε πηγή και τι απέτυχε
- `data/seen.json` — μνήμη όσων έχουν ήδη δει

Μιάμιση ώρα αργότερα, το scheduled task του Claude διαβάζει το `recent.json`, εφαρμόζει τα
κριτήρια από το Dropbox, προσθέτει Jooble και Ίδρυμα Νιάρχος, και στέλνει το PDF.

Χειροκίνητη εκτέλεση: Actions → «Συλλογή αγγελιών» → Run workflow.
